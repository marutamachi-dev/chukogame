# 500件・プラットフォーム中立カタログ設計

## 目的

国内版Nintendo Switch 2 / Nintendo Switchのパッケージソフトを、合計500件まで掲載・毎日更新する。Switch 2とSwitchの固定枠は設けず、利用者の需要に応じて内訳が変動する。

## 掲載対象

- 合計掲載数は500件。
- 国内版のパッケージソフトのみを対象とする。
- ダウンロード専売、海外版、本体・周辺機器、セット・限定版などは従来どおり除外する。
- Switch 2件数の上限・下限は設けない。需要によりSwitch 2が500件内で増減する。

## 選定と入替

- 新しい500件マスターは、Switch 2 / Switchを分けず、検証済み候補を人気・新作・網羅候補の共通順位で選定する。
- 日次の入替は、検索回数・検索ヒットなし・詳細閲覧数から算出する既存の需要スコアをプラットフォームに依存せず利用する。
- 検索ヒットなしのSwitch 2タイトルも、国内パッケージ版・JAN・カテゴリー検証を満たす場合は候補になる。
- 低需要タイトルのみを置換し、新規掲載から7日未満のタイトルは保護する。

## 更新と検証

- 500件を50件ごとの10チャンクに分け、日次更新では全10チャンクを処理する。
- Yahoo! Shoppingの販売情報は、JAN一致・中古・在庫あり・送料無料・同一プラットフォームの条件を満たすものだけを採用する。
- 当日確認できない購入価格は残さず、表示しない。
- 500件・10チャンク、プラットフォーム上限なし、需要ベースのSwitch 2入替をテストする。
