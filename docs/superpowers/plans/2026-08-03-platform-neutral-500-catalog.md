# Platform-Neutral 500-Title Catalog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expand the verified daily catalog to 500 titles while allowing demand, rather than a Switch 2 quota, to determine platform mix.

**Architecture:** `src/lib/game-master.js` owns the 500-title and 10-chunk contract. The master builder selects from one combined Switch 2 / Switch candidate pool, and the existing demand replacement stays platform-neutral.

**Tech Stack:** Node.js ESM scripts, GitHub Actions, Yahoo! Shopping API, Supabase demand telemetry, Node test runner.

## Global Constraints

- Publish exactly 500 verified domestic Nintendo Switch 2 / Nintendo Switch package titles.
- Do not impose a Switch 2 maximum or minimum quota.
- Use 50-title chunks and refresh every chunk daily.
